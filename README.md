## 🛠️ Tech Stack

- HTML5 + CSS3
- Video.js 7.20.3
- HLS.js (videojs-contrib-hls)
- Render.com (Static Hosting)

## 📱 Responsive

- Works on Desktop, Tablet, and Mobile
- Auto-adapts to screen size

## 🔄 Auto Reconnect

- Automatically attempts to reconnect if stream fails
- Shows connection status
